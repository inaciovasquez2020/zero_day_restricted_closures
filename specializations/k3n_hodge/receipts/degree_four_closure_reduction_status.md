# K3^[n] Degree-Four Closure Reduction — Status and Novelty Boundary

## Status

The current `n >= 4` K3^[n]-type ZeroDayClosure route is a conditional
reduction. It does not establish an unconditional closure theorem.

The repository separates established hyper-Kähler input from consequences
derived inside the Zero Day closure framework.

## Established mathematical inputs

The degree-four analysis uses established results and structures associated
with:

- Göttsche: Betti/Hodge data for Hilbert schemes of points on K3 surfaces.
- Verbitsky and the LLV framework: the subalgebra generated by `H^2` and its
  degree-four symmetric-square contribution.
- Kapfer: integral degree-four cup-product/cokernel structure for Hilbert
  schemes of points on K3 surfaces.
- Green–Kim–Laza–Robles: LLV decomposition information for hyper-Kähler
  cohomology, including K3^[n]-type.
- Markman: monodromy and degree-four quotient/lattice structure for
  K3^[n]-type manifolds.

These ingredients are external mathematical input and are not claimed as
discoveries of this repository.

## Repository-derived reduction

Using the encoded degree-four quotient and monodromy structure, the repository
derives the following conditional chain for `n >= 4`.

Let

    Q4(X,Q) := H^4(X,Q) / SH^4(X,Q)

and let

    gamma_X := (1/2)[c2(X)] in Q4(X,Q).

For a degree-four class `c` whose quotient has finite monodromy orbit, the
encoded monodromy classification reduces

    pi4_X(c)

to the single line

    Q * gamma_X.

The corresponding coefficient is written explicitly as

    K3nDegreeFourC2ScalarObstruction(X,n,c)
      =
    B_Q(pi4_X(c),gamma_X) / (2n - 2).

Under the finite-orbit hypothesis, the repository derives the criterion

    c in SH^4(X,Q)

if and only if

    K3nDegreeFourC2ScalarObstruction(X,n,c) = 0.

Thus the finite-orbit degree-four obstruction is reduced to one rational
scalar.

The repository further derives that an independent finite-orbit assumption
for each required degree-four class is unnecessary if the required-class
inventory is itself finite and carries a degree-preserving, class-equivariant
monodromy action. Under those assumptions, each required class has finite
monodromy orbit because its orbit is contained in the finite image of the
required-class index set.

Combining these statements yields the current conditional closure reduction:

    finite monodromy-stable required inventory
    +
    non-degree-four required classes lie in SH
    +
    explicit degree-four c2/2 scalar obstruction vanishes
    =>
    RequiredClassesSubsetSH
    =>
    ZeroDayClosure.

## What is distinctive here

The repository-specific contribution is the organization of the known
hyper-Kähler inputs into this explicit ZeroDayClosure obstruction mechanism:

1. isolate the degree-four quotient;
2. collapse finite-orbit quotient directions to the `c2/2` line;
3. express the remaining degree-four obstruction as one explicit scalar;
4. derive finite class orbits from a finite equivariant required-class
   inventory rather than assuming them separately; and
5. feed these reductions into the repository's `RequiredClassesSubsetSH ->
   ZeroDayClosure` architecture.

This is appropriately described as a repository-derived conditional reduction
and synthesis.

No claim is made here that the underlying Göttsche, Verbitsky/LLV, Kapfer,
Green–Kim–Laza–Robles, or Markman results are new.

No claim is made here that every individual intermediate consequence is absent
from the mathematical literature. The exact ZeroDayClosure formulation and
its use of the single-scalar obstruction belong to the repository's own
framework, while literature-level novelty of the derived hyper-Kähler
consequences is not asserted.

## Remaining boundary

The repository does not currently provide an independent witness for:

- finiteness of the required-class index inventory;
- a monodromy action on that inventory with the required equivariance;
- membership in `SH` for all non-degree-four required classes; or
- vanishing of the explicit `c2/2` scalar obstruction for actual required
  degree-four classes.

The repository audit found no independent derivation of those inputs outside
the conditional closure surface.

Therefore:

    unconditional ZeroDayClosure for n >= 4 is not proved.

No required-class inventory element is manufactured to bypass this boundary.

The stopped K3^[3] required-class inventory branch remains stopped.
